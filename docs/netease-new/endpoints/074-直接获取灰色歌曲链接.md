# 直接获取灰色歌曲链接

> **接口路径（摘自原文）:** `/song/url/match`

**文档说明:** 接口与 [NeteaseCloudMusicApiEnhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced) 约定一致；正文来自仓库内 `docs/netease-new/API.md` 并按章节拆分。API 基地址由应用配置提供，文档不写死服务端点。

---

说明 : 技术部分来自于 [UnblockNeteaseMusic](https://github.com/unblockneteasemusic/server) 的支持

**必选参数 :** `id` : 音乐 id

**可选参数 :** `source`: 选择要解灰的音源, 不支持多音源

**接口地址 :** `/song/url/match`

**调用例子 :** `/song/url/match?id=1969519579` `/song/url/match?id=1969519579`
