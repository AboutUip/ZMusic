# 助眠解压 - 获取标签下资源列表

> **接口路径（摘自原文）:** `/sati/resource/list`

**文档说明:** 接口与 [NeteaseCloudMusicApiEnhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced) 约定一致；正文来自仓库内 `docs/netease-new/API.md` 并按章节拆分。API 基地址由应用配置提供，文档不写死服务端点。

---

说明: 调用此接口, 获取标签下资源列表; 接口返回的`trackId`可以用于请求`/song/url/v1`接口，用于获取声音的下载地址

**必选参数 :**

`tag`: 标签, 由标签列表接口得到

**接口地址:** `/sati/resource/list`

**调用例子:** `/sati/resource/list?tag=naturalMusic`
