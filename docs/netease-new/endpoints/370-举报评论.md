# 举报评论

> **接口路径（摘自原文）:** `/comment/report`

**文档说明:** 接口与 [NeteaseCloudMusicApiEnhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced) 约定一致；正文来自仓库内 `docs/netease-new/API.md` 并按章节拆分。API 基地址由应用配置提供，文档不写死服务端点。

---

说明 : 登录后调用此接口, 传入歌曲 id 和评论 id, 举报评论

**必选参数 :**

`id`: 歌曲 id

`cid`: 评论 id

`reason`: 举报理由

**接口地址 :** `/comment/report`

*_调用例子 :_ `/comment/report?id=2058263032&cid=123456789&reason=人身攻击`
