# 云小编 - 每日抽奖

> **接口路径（摘自原文）:** `/middle/play/do/lottery`

**文档说明:** 接口与 [NeteaseCloudMusicApiEnhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced) 约定一致；正文来自仓库内 `docs/netease-new/API.md` 并按章节拆分。API 基地址由应用配置提供，文档不写死服务端点。

---

说明: 登录后调用此接口, 消耗 200 积分进行抽奖, 每日最多抽 3 次

> 注意: 抽奖失败也消耗每日次数, 请先调用 `/rep/ugc/user/get` 查询可用积分

**可选参数:**

`activityId`: 活动 ID, 默认 `6501202`

`drawCount`: 未知, 默认 `1`

`checkToken`: 易盾反作弊 Token, 默认自动获取

**接口地址:** `/middle/play/do/lottery`

**调用例子:** `/middle/play/do/lottery?activityId=6501202&drawCount=1`
