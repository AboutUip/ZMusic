# 广播电台 - 全部电台

> **接口路径（摘自原文）:** `/broadcast/channel/list`

**文档说明:** 接口与 [NeteaseCloudMusicApiEnhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced) 约定一致；正文来自仓库内 `docs/netease-new/API.md` 并按章节拆分。API 基地址由应用配置提供，文档不写死服务端点。

---

说明: 调用此接口, 获取广播电台 - 全部电台

**可选参数 :**

`categoryId` : 类别 id, 默认为 0，可从“广播电台 - 分类/地区信息”接口获取

`regionId` : 地区 id, 默认为 0，可从“广播电台 - 分类/地区信息”接口获取

**接口地址:** `/broadcast/channel/list`

**调用例子:** `/broadcast/channel/list`
