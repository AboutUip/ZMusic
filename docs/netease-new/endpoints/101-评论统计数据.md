# 评论统计数据

> **接口路径（摘自原文）:** `/comment/info/list`

**文档说明:** 接口与 [NeteaseCloudMusicApiEnhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced) 约定一致；正文来自仓库内 `docs/netease-new/API.md` 并按章节拆分。API 基地址由应用配置提供，文档不写死服务端点。

---

说明 : 调用此接口 , 传入资源类型和资源 id 列表 , 可批量获取对应资源的评论统计数据 ( 不需要登录 )

**必选参数 :**

`type`: 数字 , 资源类型 , 对应以下类型

```
0: 歌曲

1: mv

2: 歌单

3: 专辑

4: 电台节目

5: 视频

6: 动态

7: 电台
```

`ids`: 资源 id 列表 , 多个 id 用逗号分隔 , 如 `186016,347230`

**接口地址 :** `/comment/info/list`

**调用例子 :** `/comment/info/list?type=0&ids=186016,347230`

**返回数据 :**

```json
{
  "data": [
    {
      "latestLikedUsers": null,
      "liked": false,
      "comments": null,
      "resourceType": 4,
      "resourceId": 186016,
      "commentUpgraded": false,
      "musicianSaidCount": 0,
      "commentCountDesc": "100w+",
      "likedCount": 347,
      "commentCount": 1970844,
      "shareCount": 109721,
      "threadId": "R_SO_4_186016"
    }
  ],
  "code": 200
}
```
