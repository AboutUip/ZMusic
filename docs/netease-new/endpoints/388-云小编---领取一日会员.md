# 云小编 - 领取一日会员

> **接口路径（摘自原文）:** `/rep/ugc/user/collect-vip`

**文档说明:** 接口与 [NeteaseCloudMusicApiEnhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced) 约定一致；正文来自仓库内 `docs/netease-new/API.md` 并按章节拆分。API 基地址由应用配置提供，文档不写死服务端点。

---

说明: 达成领取条件 (`/rep/ugc/user/vip`) 后调用此接口, 领取一日会员

**可选参数:**

`activityId`: 活动 ID, 调用 `/rep/ugc/activity/get` 获取, 默认 `5001`

**接口地址:** `/rep/ugc/user/collect-vip`

**调用例子:** `/rep/ugc/user/collect-vip?activityId=5001`
