# 喜欢歌曲 - 新版

> **接口路径（摘自原文）:** `/song/like`

**文档说明:** 接口与 [NeteaseCloudMusicApiEnhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced) 约定一致；正文来自仓库内 `docs/netease-new/API.md` 并按章节拆分。API 基地址由应用配置提供，文档不写死服务端点。

---

说明 : 登录后调用此接口, 传入歌曲 id 用户id和喜欢状态, 可喜欢/取消喜欢歌曲

**必选参数 :**

`id`: 歌曲 id
`uid`: 用户 id
`like`: 喜欢状态, true 表示喜欢, false 表示取消喜欢

**接口地址 :** `/song/like`

**调用例子 :** `/song/like?id=2058263032&uid=32953014&like=true`
