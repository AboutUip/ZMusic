# 听歌足迹 - 歌曲播放排行

> **接口路径（摘自原文）:** `/listen/data/song/play/rank`

**文档说明:** 接口与 [NeteaseCloudMusicApiEnhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced) 约定一致；正文来自仓库内 `docs/netease-new/API.md` 并按章节拆分。API 基地址由应用配置提供，文档不写死服务端点。

---

说明 : 登录后调用此接口, 获取歌曲播放排行, 返回每首歌的播放次数 (playCount); 默认返回前 20 名 (Top20), 不足则返回全部

**必选参数 :**

`type`: 维度类型 周 week 月 month

**可选参数 :**

`endTime` : 周: 每周周六 0 点的时间戳 月: 每月最后一天 0 点的时间戳
不填就是本周/月的

**接口地址 :** `/listen/data/song/play/rank`

**调用例子 :** `/listen/data/song/play/rank?type=month`
