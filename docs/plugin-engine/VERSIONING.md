# 版本编码

插件能否加载只取决于 **引擎版本**，与宿主应用程序版本无关。应用程序版本可通过运行时只读属性读取，见 [RUNTIME.md](./RUNTIME.md)。

| 版本 | 展示 | 清单中的整数 |
|---|---|---|
| 包格式 | — | `plugin.json` 的 `zpp`，当前 `1` |
| 引擎 | `0.0.0`（三段） | `engine.min` / `engine.max` |
| 插件 | `v 00.00`（两段） | `plugin.json` 的 `version` |

清单字段均为整数。展示串用于阅读与运行时只读属性；整数由展示串按下列规则换算，每段取值 `0–99`，必须先补齐两位再去掉小数点，否则 `0.1.12` 与 `0.11.2` 会冲突。

## 引擎版本（三段）

展示：`major.minor.patch`，没有 `v`，不补零。换算成整数时每段仍先补齐两位再拼接，否则 `0.1.12` 与 `0.11.2` 会冲突。

| 段 | 用途 | 示例展示 | 整数 |
|---|---|---|---|
| 第一段 | 超大更新 | `1.0.0` | `10000` |
| 第二段 | 大更新 / 重要更新 | `0.1.0` | `100` |
| 第三段 | 小更新 | `0.0.1` | `1` |

```
整数 = major × 10000 + minor × 100 + patch
```

| 展示 | 六位 | 整数 |
|---|---|---|
| `0.0.1` | `000001` | `1` |
| `0.0.2` | `000002` | `2` |
| `0.1.0` | `000100` | `100` |
| `0.1.2` | `000102` | `102` |
| `1.22.3` | `012203` | `12203` |

当前引擎：`0.1.0`，整数 `100`。

超大更新时后两段归零；大更新时第三段归零。

**向后兼容：** 引擎升级不得撤销已对插件开放的能力。未设置 `engine.max` 的包在新引擎上仍可加载。`engine.max` 表示作者主动排除更高引擎，宿主必须遵守。

`plugin.json` 的 `capabilities` 给工坊 / 用户看「这个包装了什么」，**不是**运行时门锁。已实现的 `Xuan` API 对 `Running` 插件均可调用，不必先声明。

核心 API（`hook` / `timer` / `require` / `pack` / 通知 / 延迟等）不写进 `capabilities`。只有真正可选、且值得在商店里标出来的能力才登记。

### 本引擎已知能力（展示用）

| 名称 | 说明 |
|---|---|
| `theme` | 宿主主题：`Xuan.theme`，见 [THEME.md](./THEME.md) |
| `player` | 播放快照与控制：`Xuan.player`，见 [PLAYER.md](./PLAYER.md) |
| `http` | 出站网络：`Xuan.http`，见 [HTTP.md](./HTTP.md) |
| `store` | 持久键值：`Xuan.store`，见 [STORE.md](./STORE.md) |
| `ui` | 槽位、组件树页面、弹窗与 sheet：`Xuan.ui`，见 [UI.md](./UI.md) |
| `media` | 保存图片到相册：`Xuan.media`，见 [DEVICE.md](./DEVICE.md) |
| `share` | 系统分享：`Xuan.share`，见 [DEVICE.md](./DEVICE.md) |
| `clipboard` | 剪贴板：`Xuan.clipboard`，见 [DEVICE.md](./DEVICE.md) |

字段可省略或 `[]`。写出时：空串去掉；**未知名忽略**，整包仍有效（便于旧客户端不认识的新名字）。非字符串项则清单无效。

## 插件版本（两段）

展示：`v MM.mm`。禁止第三段。

```
整数 = major × 100 + minor
```

| 展示 | 四位 | 整数 |
|---|---|---|
| `v 00.01` | `0001` | `1` |
| `v 01.22` | `0122` | `122` |

同一 `id` 下，更大的整数覆盖较小的版本。

## 包格式版本

`zpp` 在必选文件集合或清单出现不兼容的必填字段时加一。仅向资源白名单追加扩展名，或增加可忽略的可选字段，可以保持 `1`。
