# 版本编码

插件能否加载只取决于 **引擎版本**，与宿主应用程序版本无关。应用程序版本可通过运行时只读属性读取，见 [RUNTIME.md](./RUNTIME.md)。

| 版本 | 展示 | 清单中的整数 |
|---|---|---|
| 包格式 | — | `plugin.json` 的 `zpp`，当前 `1` |
| 引擎 | `0.0.0`（三段） | `engine.min` / `engine.max` |
| 插件 | `v 00.00`（两段） | `plugin.json` 的 `version` |

清单字段均为整数。展示串用于阅读与运行时只读属性；整数由展示串按下列规则换算，每段取值 `0–99`，必须先补齐两位再去掉小数点，否则 `0.1.12` 与 `0.11.2` 会冲突。

## 引擎版本（三段）

展示：`major.minor.patch`，没有 `v`，不补零。换算成整数时每段仍先补齐两位再拼接，否则 `0.1.12` 与 `0.11.2` 会冲突。

| 段 | 用途 | 示例展示 | 整数 |
|---|---|---|---|
| 第一段 | 超大更新 | `1.0.0` | `10000` |
| 第二段 | 大更新 / 重要更新 | `0.1.0` | `100` |
| 第三段 | 小更新 | `0.0.1` | `1` |

```
整数 = major × 10000 + minor × 100 + patch
```

| 展示 | 六位 | 整数 |
|---|---|---|
| `0.0.1` | `000001` | `1` |
| `0.0.2` | `000002` | `2` |
| `0.1.2` | `000102` | `102` |
| `1.22.3` | `012203` | `12203` |

当前引擎：`0.0.2`，整数 `2`。

超大更新时后两段归零；大更新时第三段归零。

**向后兼容：** 引擎升级不得撤销已对插件开放的能力。未设置 `engine.max` 的包在新引擎上仍可加载。`engine.max` 表示作者主动排除更高引擎，宿主必须遵守。

`plugin.json` 的 `capabilities` 用于声明可选能力。新增可选 API 时记入 `capabilities`，不必仅靠提升引擎版本区分。

### 本引擎已知能力

| 名称 | 说明 |
|---|---|
| `theme` | 文本主题：`Xuan.theme`，见 [THEME.md](./THEME.md) |

字段可省略或 `[]`。若写出，每一项必须是上表名称；未知字符串则整包无法加载。

## 插件版本（两段）

展示：`v MM.mm`。禁止第三段。

```
整数 = major × 100 + minor
```

| 展示 | 四位 | 整数 |
|---|---|---|
| `v 00.01` | `0001` | `1` |
| `v 01.22` | `0122` | `122` |

同一 `id` 下，更大的整数覆盖较小的版本。

## 包格式版本

`zpp` 在必选文件集合或清单出现不兼容的必填字段时加一。仅向资源白名单追加扩展名，或增加可忽略的可选字段，可以保持 `1`。
